# chat-simple
一个最简单的聊天工具

#### 介绍
- 前端：vite+vue3+socket.io-client完成前端聊天框界面
- 后端：使用nestjs完成websocket

#### 安装教程

1.  frontend表示前端目录，使用`npm create vite@latest fronted -- --template vue` 命令创建
2.  server表示后端目录，使用`nest new server`创建

#### 使用说明

1.  前端运行命令 `cd frontend && npm i && npm run dev`
2.  后端运行命令 `cd server && npm i && npm run start`
